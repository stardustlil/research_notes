# 笔记规范

上级：[[首页|笔记首页]]

> [!abstract] 本篇的作用
> 规定笔记的种类、统一大纲、层次关系和链接方式。新增或扩展笔记时按本篇执行；公式符号见 [[数学符号约定]]。

## 1. 笔记的三种类型

| 类型 | 作用 | 标签 | 例子 |
| --- | --- | --- | --- |
| 约定笔记 | 全库通用的规则 | `约定` | [[数学符号约定]]、本篇 |
| 主题索引 | 一个主题的导航与横向对比，**不写推导和代码** | `索引` + `Transformer/主题` | [[Normalization]]、[[Attention]]、[[Position Encode]] |
| 概念笔记 | 一个具体结构或方法的完整讲解 | `Transformer/主题[/子主题]` | [[LayerNorm]]、[[RoPE]] |

层次关系只有三层：**首页 → 主题索引 → 概念笔记**。每篇概念笔记有且只有一个「上级」，可以有多个「前置」。

## 2. 概念笔记的统一大纲

一级标题之后依次是下面这些二级标题，**名称和顺序固定**（其他笔记会按标题名链接，例如 `[[RoPE#定义]]`，所以二级标题不加序号、不改名）。

| 二级标题 | 是否必选 | 写什么 |
| --- | --- | --- |
| （标题区） | 必选 | `上级：[[主题索引]]`，有前置知识时加 `｜ 前置：[[...]]`；再用一个 `[!abstract]` 提示框写总结 |
| 动机 | 必选 | 要解决什么问题；之前的做法差在哪里 |
| 符号 | 必选 | 输入、输出及其形状；本篇新引入的局部符号**必须**在此定义。已在[[数学符号约定]]登记的核心符号可以复述，方便单篇阅读，但含义不得改变 |
| 定义 | 必选 | 核心公式，按计算顺序逐步写出；每个新矩阵第一次出现时标注形状 |
| 性质与推导 | 可选 | 关键性质、证明、几何直觉；可分多个三级标题 |
| 代码实现 | 必选 | PyTorch 实现：变量名与数学符号一一对应，关键行注释形状 |
| 对比与易错点 | 可选 | 与相近方法的区别、常见误区、和论文 / 框架实现的差异 |
| 相关笔记 | 必选 | `- [[链接]]：一句话说明两者的关系` |

> [!tip] 写作顺序
> 先写「符号」和「定义」，确认数学上闭合（每个符号都有定义、每个形状都对得上），再写「代码实现」。代码只是把定义翻译成张量操作。

## 3. 主题索引的统一大纲

| 二级标题 | 写什么 |
| --- | --- |
| （标题区） | `上级：[[首页]]` + `[!abstract]` 一句话说明本主题讨论什么 |
| 学习顺序 | 用 `→` 串起本主题笔记的推荐阅读顺序 |
| 笔记导航 | 每篇概念笔记一行：`- [[笔记]]：一句话要点`；可用缩进子项列出重点章节或子主题 |
| 快速对比 | 横向对比表格（只放结论，推导留在概念笔记） |
| 相关主题 | 指向其他主题索引 |

## 4. 代码实现的规范

- 只依赖 `torch`（和 `math`），代码块开头写全 `import`，复制即可运行。若复用其他笔记中的函数（如 YaRN 复用 RoPE 的 `apply_rope`），在代码块开头用注释注明来源。
- 变量名按 [[数学符号约定#6. 数学 ↔ 代码对照|数学 ↔ 代码对照表]]：$X$ → `x`，$S$ → `scores`，$A$ → `attn`，$t_i$ → `t`，$\omega_r$ → `omega`……
- 每个产生新张量的关键行，在行尾注释形状，如 `# [B, n, d_k]`。
- 能和 PyTorch 官方实现对照时（如 `nn.LayerNorm`），在「对比与易错点」中说明二者的关系。

## 5. 文件、标签与链接

- 目录按主题编号：`00 约定/`、`01 归一化/`、`02 注意力/`、`03 位置编码/`；子主题放子目录，例如 `03 位置编码/长上下文/`。
- 概念笔记与主题索引的文件名用英文；概念笔记的一级标题写「英文名（中文名）」，主题索引的一级标题写中文主题名；中文名写进 `aliases`，插入链接时输入 `[[` 可以搜到中英文名。首页和约定笔记直接用中文名。
- 标签：概念笔记用 `Transformer/主题[/子主题]`，索引笔记再加 `索引`。
- 图片等附件放在 `attachments/`。
- 链接到具体章节时写 `[[笔记#标题|显示文字]]`。
- 标题中不写公式（`$...$` 会让章节链接失效），需要时用文字描述，如「为什么要缩放」。

## 6. 新增一篇笔记的检查清单

1. 用 Obsidian 的「插入模板」功能，从 `00 约定/模板/` 中选择 [[概念笔记模板]] 或 [[主题索引模板]]。
2. 填写 `aliases`、`tags`、上级和前置。
3. 新符号先在 [[数学符号约定]] 登记，确认不和已有符号冲突。
4. 在所属主题索引的「学习顺序」「笔记导航」中加上这篇；必要时更新「快速对比」。
5. 在相关笔记的「相关笔记」一节中加回链。
