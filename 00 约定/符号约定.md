# 符号约定

全库公式以本篇为准。新符号先在此登记，再在笔记中使用。

## 基本约定

### 行向量

token 表示是行向量，矩阵按行堆叠 token，线性变换右乘（与 PyTorch 的 `x @ W` 一致）：

$$
x_i\in\mathbb{R}^{1\times d},\qquad
X=\begin{bmatrix}x_1\\ \vdots\\ x_n\end{bmatrix}\in\mathbb{R}^{n\times d},\qquad
y=xW,\quad W\in\mathbb{R}^{d_{\text{in}}\times d_{\text{out}}}.
$$

内积写作 $uv^\top$。

### 下标起点

只用来取元素的下标从 $1$ 开始；数值要代入公式的编号从 $0$ 开始。

| 编号 | 起点 | 范围 | 例子 |
| --- | --- | --- | --- |
| token $i,j$ | 1 | $1,\dots,n$ | $x_i$、$S_{ij}$ |
| 特征 $c$ | 1 | $1,\dots,d$ | $x_{i,c}$、$\gamma_c$ |
| 头 $h$ | 1 | $1,\dots,H$ | $Q^{(h)}$ |
| 位置 $t$ | 0 | $0,\dots,n-1$ | $t_i=i-1$ |
| 频率组 $r$ | 0 | $0,\dots,d_k/2-1$ | $\omega_r=b^{-2r/d_k}$ |

第 $r$ 组对应第 $2r+1$、$2r+2$ 个分量。代码中 `torch.arange(n)` 即 $t_1,\dots,t_n$。

### 字体

| 对象 | 写法 | 例子 |
| --- | --- | --- |
| 标量 | 小写斜体 | $n$、$d$、$\epsilon$ |
| 行向量 | 小写斜体，与所在矩阵同字母，一个下标 | $x_i$ 是 $X$ 的第 $i$ 行 |
| 矩阵 | 大写斜体 | $X$、$W_Q$、$A$ |
| 分量 / 元素 | 两个下标 | $x_{i,c}=X_{ic}$、$S_{ij}$ |
| 集合 | 花体 | $\mathcal{S}$ |
| 多字母函数 | `\operatorname` | $\operatorname{softmax}$、$\operatorname{RMS}$ |
| 文字下标 | `\text` | $n_{\text{train}}$ |

不用粗体。

### 修饰符

| 修饰符 | 含义 | 例子 |
| --- | --- | --- |
| $\hat{\ }$ | 归一化后 | $\hat x$ |
| $\tilde{\ }$ | 注入位置信息后 | $\tilde X=X+P_{1:n}$、$\tilde q_i=q_iR(t_i)$ |
| $'$ | 同一量的修改版 | $S'=S+M$、$\omega'_r$ |
| $\bar{\ }$ | 平均值 | $\bar S_i$ |
| 上标 $(h)$ | 第 $h$ 个头 | $W_Q^{(h)}$ |
| 上标 $\text{run}$ | 滑动统计量 | $\mu_c^{\text{run}}$ |

## 维度

| 符号 | 含义 | 代码 |
| --- | --- | --- |
| $B$ | batch 大小 | `B` |
| $n$ | 序列长度 | `n` |
| $n_{\max}$ | 位置表最大长度 | `max_len` |
| $n_{\text{train}},n_{\text{ext}}$ | 训练窗口、扩展后窗口 | `n_train`、`n_ext` |
| $d$ | 模型维度 | `d` |
| $H$ | 头数 | `H` |
| $d_k,d_v$ | 单头 query/key、value 维度 | `d_k`、`d_v` |
| $C,H_{\text{img}},W_{\text{img}}$ | 通道、图像高宽 | `C`、`H_img`、`W_img` |
| $m$ | 统计集合大小 $\lvert\mathcal{S}\rvert$ | `m` |

公式默认省略 batch 维；代码注释写 `[B, n, d]`。

| 字母 | 用途 |

| 符号 | 含义 |
| --- | --- |
| $\mathcal{S}$ | 统计集合 |

### 注意力

| 符号 | 形状 | 含义 |
| --- | --- | --- |
| $W_Q,W_K$ | $d\times d_k$ | query、key 投影 |
| $W_V$ | $d\times d_v$ | value 投影 |
| $W_O$ | $Hd_v\times d$ | 输出投影 |
| $Q,K,V$ | $n\times d_k$、$n\times d_k$、$n\times d_v$ | 第 $i$ 行为 $q_i,k_i,v_i$ |
| $S$ | $n\times n$ | $QK^\top/\sqrt{d_k}$ |
| $M$ | $n\times n$ | 加性 mask，元素为 $0$ 或 $-\infty$ |
| $A$ | $n\times n$ | $\operatorname{softmax}(S+M)$ |
| $O$ | $n\times d_v$ | $AV$ |
| $O_{\text{cat}}$ | $n\times Hd_v$ | 多头拼接 |
| $Y$ | $n\times d$ | $O_{\text{cat}}W_O$ |

### 位置编码

| 符号 | 含义 |
| --- | --- |
| $t_i$ | $i-1$ |
| $P$ | 位置矩阵 $\in\mathbb{R}^{n_{\max}\times d}$，第 $i$ 行 $p_i$；$P_{1:n}$ 为前 $n$ 行 |
| $\operatorname{PE}(t)$ | 正余弦位置向量 $\in\mathbb{R}^{1\times d}$ |
| $b$ | 频率底数，原始取 $10000$ |
| $\omega_r$ | $b^{-2r/d_k}$（正余弦编码中 $d_k$ 换成 $d$） |
| $\theta_{i,r}$ | $t_i\omega_r$ |
| $R_\omega(t)$ | $2\times2$ 旋转矩阵（右乘） |
| $R(t)$ | $\operatorname{diag}(R_{\omega_0}(t),\dots)$，$d_k\times d_k$ |

### 长上下文

| 符号 | 含义 |
| --- | --- |
| $s$ | $n_{\text{ext}}/n_{\text{train}}$ |
| $\lambda_r$ | 波长 $2\pi/\omega_r$ |
| $\rho_r$ | 圈数 $n_{\text{train}}/\lambda_r$ |
| $\rho_{\text{lo}},\rho_{\text{hi}}$ | 圈数阈值 |
| $\xi_r$ | 保留原频率的比例 |
| $\tau$ | softmax 温度 |
| $\alpha$ | $q,k$ 幅度倍率，$\tau=1/\alpha^2$ |

### 论文写法对照

| 来源 | 原写法 | 本库 | 原因 |
| --- | --- | --- | --- |
| Transformer | $PE(pos,2i)$ | $\operatorname{PE}(t)_{2r+1}$ | $i$ 是 token 下标 |
| Transformer | $d_{\text{model}}$ | $d$ | |
| PyTorch BatchNorm2d | `(N, C, H, W)` | $(B,C,H_{\text{img}},W_{\text{img}})$ | $N,H,W$ 已占用 |
| PyTorch | `momentum` | $\kappa$ | $m$ 是集合大小 |
| YaRN | $L,L'$ | $n_{\text{train}},n_{\text{ext}}$ | |
| YaRN | $\gamma(r),\alpha,\beta$ | $\xi_r,\rho_{\text{lo}},\rho_{\text{hi}}$ | $\gamma,\beta$ 属于归一化 |
| YaRN | 温度 $t$ | $\tau$ | $t$ 是位置 |

## 常用运算

行 softmax（全库 softmax 都按行，代码 `dim=-1`）：

$$
\operatorname{softmax}(Z)_{ij}=\frac{\exp(Z_{ij})}{\sum_{j'=1}^{n}\exp(Z_{ij'})}.
$$

因果 mask：

$$
M_{ij}=
\begin{cases}
0, & j\le i,\\
-\infty, & j>i.
\end{cases}
$$

$\operatorname{Concat}$ 沿特征维拼接；$\operatorname{diag}(R_1,\dots,R_k)$ 为块对角矩阵。

## LaTeX

- 转置 `^\top`；多字母函数 `\operatorname{}`；文字下标 `\text{}`。
- 多行公式用 `aligned`，公式块内不留空行。
- 用 `\tilde`、`\hat`，不用 `\widetilde`、`\widehat`。
- 句末标点写在公式块内。
