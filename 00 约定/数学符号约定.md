# 数学符号约定

上级：[[首页|笔记首页]]

> [!abstract] 本篇的作用
> 全库所有公式都以本篇为准。写新笔记前先查这里；如果需要一个新符号，**先在本篇登记，再在笔记里使用**。各笔记的「符号」一节只列本篇没有的局部符号。

## 1. 基本约定

### 1.1 行向量约定

每个 token 的表示是**行向量**，矩阵按行堆叠 token，线性变换写成**右乘**：

$$
x_i\in\mathbb{R}^{1\times d},\qquad
X=\begin{bmatrix}x_1\\ \vdots\\ x_n\end{bmatrix}\in\mathbb{R}^{n\times d},\qquad
y=xW,\quad W\in\mathbb{R}^{d_{\text{in}}\times d_{\text{out}}}.
$$

这与 PyTorch 中 `x @ W` 的写法一致：张量最后一维是特征维，矩阵乘法作用在最后一维上。

两个行向量的内积写作 $uv^\top$（结果是标量）。

### 1.2 下标从几开始

**规则：只用来「取第几个元素」的下标从 $1$ 开始；数值本身会「代入公式计算」的编号从 $0$ 开始。**

| 编号             | 起点  | 范围                | 例子                              |
| -------------- | --- | ----------------- | ------------------------------- |
| token 下标 $i,j$ | 1   | $1,\dots,n$       | $x_i$、$S_{ij}$、$\sum_{j=1}^{n}$ |
| 特征下标 $c$       | 1   | $1,\dots,d$       | $x_{i,c}$、$\gamma_c$            |
| 头下标 $h$        | 1   | $1,\dots,H$       | $Q^{(h)}$                       |
| 位置编号 $t$       | 0   | $0,\dots,n-1$     | $t_i=i-1$，代入 $\theta=t\,\omega$ |
| 频率分组 $r$       | 0   | $0,\dots,d_k/2-1$ | $\omega_r=b^{-2r/d_k}$          |

两套编号通过 $t_i=i-1$ 连接：第 $i$ 个 token 的位置编号是 $t_i$。代码里 `torch.arange(n)` 得到的正是 $t_1,\dots,t_n$。

频率分组 $r$ 对应的两个分量（按 1 起的分量编号）是第 $2r+1$ 和第 $2r+2$ 个分量。

### 1.3 字体与大小写

| 对象     | 写法                 | 例子                                                                    |
| ------ | ------------------ | --------------------------------------------------------------------- |
| 标量     | 小写斜体               | $n$、$d$、$\epsilon$、$s$                                                |
| 行向量    | 小写斜体，与所在矩阵同字母      | $x_i$ 是 $X$ 的第 $i$ 行，$q_i$ 是 $Q$ 的第 $i$ 行                             |
| 矩阵     | 大写斜体               | $X$、$W_Q$、$S$、$A$                                                     |
| 矩阵元素   | 大写 + 双下标           | $S_{ij}$、$A_{ij}$                                                     |
| 行向量分量  | 小写 + 「行, 分量」双下标    | $x_{i,c}=X_{ic}$                                                      |
| 集合     | 花体                 | $\mathcal{S}$（统计集合）                                                   |
| 多字母函数名 | `\operatorname` 正体 | $\operatorname{softmax}$、$\operatorname{RMS}$、$\operatorname{Concat}$ |
| 文字型下标  | `\text` 正体         | $n_{\text{train}}$、$\rho_{\text{lo}}$                                 |

不对向量使用粗体。区分方式：**一个下标的小写字母是行向量，两个下标的是标量分量**。

### 1.4 修饰符的含义

每种修饰符在全库只有一种含义：

| 修饰符 | 含义 | 例子 |
| --- | --- | --- |
| $\hat{\ }$（hat） | 归一化后的量 | $\hat x$：减均值、除标准差后的输入 |
| $\tilde{\ }$（tilde） | 注入位置信息后的量 | $\tilde X=X+P_{1:n}$；$\tilde q_i=q_iR(t_i)$ |
| $'$（prime） | 同一个量的修改版本 | $S'=S+M$（加 mask 后）；$\omega'_r$（插值后） |
| $\bar{\ }$（bar） | 平均值 | $\bar z$ |
| 上标 $(h)$ | 第 $h$ 个注意力头 | $W_Q^{(h)}$、$A^{(h)}$ |
| 上标 $\text{run}$ | 训练中维护的滑动统计量 | $\mu_c^{\text{run}}$ |

下标保留给「取元素」，因此头编号一律写在**上标括号**里。

## 2. 维度与形状

| 符号 | 含义 | 代码名 |
| --- | --- | --- |
| $B$ | batch 大小 | `B` |
| $n$ | 序列长度（token 数） | `n` |
| $n_{\max}$ | 位置表支持的最大长度 | `max_len` |
| $n_{\text{train}}$ | 预训练时的上下文窗口 | `n_train` |
| $n_{\text{ext}}$ | 扩展后的目标上下文窗口 | `n_ext` |
| $d$ | 模型维度（论文中的 $d_{\text{model}}$） | `d_model` |
| $H$ | 注意力头数 | `num_heads` |
| $d_k$ | 每个头 query / key 的维度；RoPE 的旋转维度 | `d_k`（MHA 中为 `head_dim`） |
| $d_v$ | 每个头 value 的维度 | `d_v` |
| $C$ | 图像通道数（BatchNorm） | `C` |
| $H_{\text{img}},W_{\text{img}}$ | 图像高、宽（BatchNorm） | `H_img`、`W_img` |
| $m$ | 统计集合的元素个数 $m=\lvert\mathcal{S}\rvert$ | `m` |

**形状写法**：数学里写 $\mathbb{R}^{n\times d}$，代码注释里写 `[B, n, d]`。数学公式默认省略 batch 维度，需要时写成 $\mathbb{R}^{B\times n\times d}$。

**形状标注规则**：每个矩阵第一次出现时，写出它属于哪个 $\mathbb{R}^{\cdots}$。

## 3. 下标字母分工

| 字母 | 专用于 | 说明 |
| --- | --- | --- |
| $i$ | query 侧 token / 当前 token | $1,\dots,n$ |
| $j$ | key 侧 token | $1,\dots,n$ |
| $j'$ | 对 key 求和的哑变量 | 用在 softmax 分母 |
| $c$ | 特征维 / 通道 | 避免与 key 向量 $k$ 冲突 |
| $h$ | 注意力头 | 写在上标 $(h)$ |
| $r$ | RoPE 频率分组 | 0 起 |
| $t$ | 位置编号的值 | 0 起，$t_i=i-1$ |

## 4. 保留符号表

### 4.1 通用

| 符号 | 含义 |
| --- | --- |
| $\mathbb{R}$ | 实数集 |
| $^\top$ | 转置（统一用 `^\top`，不用 `^T`） |
| $\odot$ | 逐元素乘法 |
| $\lVert u\rVert$ | 向量的 $\ell_2$ 范数 |
| $\epsilon$ | 数值稳定小常数 |
| $I$ | 单位矩阵 |
| $\mathbb{E}[\cdot]$、$\operatorname{Var}(\cdot)$ | 期望、方差（概率意义上） |
| $\Pi$ | 置换矩阵（$\Pi X$ 表示重排 $X$ 的行） |
| $\Delta$ | 位置偏移或位置差，如 $\operatorname{PE}(t+\Delta)$、$\Delta\theta_r$ |

### 4.2 归一化

| 符号 | 含义 |
| --- | --- |
| $\mathcal{S}$ | 统计集合：一次求均值 / 方差时参与统计的所有元素 |
| $m$ | 统计集合大小 $\lvert\mathcal{S}\rvert$ |
| $\mu$、$\sigma^2$ | 统计集合上的均值、有偏方差（除以 $m$） |
| $\hat x$ | 归一化后的输入 |
| $\gamma$、$\beta$ | 可学习的缩放、平移参数（只在归一化中使用这两个字母） |
| $\kappa$ | 滑动平均动量（PyTorch 的 `momentum`） |
| $\operatorname{RMS}(x)$ | 均方根 |

### 4.3 注意力

| 符号 | 形状 | 含义 |
| --- | --- | --- |
| $X$ | $n\times d$ | 注意力层输入 |
| $W_Q,W_K$ | $d\times d_k$ | query、key 投影矩阵 |
| $W_V$ | $d\times d_v$ | value 投影矩阵 |
| $W_O$ | $Hd_v\times d$ | 多头输出投影矩阵 |
| $Q,K,V$ | $n\times d_k$、$n\times d_k$、$n\times d_v$ | query、key、value 矩阵；第 $i$ 行为 $q_i,k_i,v_i$ |
| $S$ | $n\times n$ | 缩放点积分数 $QK^\top/\sqrt{d_k}$ |
| $M$ | $n\times n$ | 加性 mask，元素取 $0$ 或 $-\infty$ |
| $S'$ | $n\times n$ | 加 mask 后的分数 $S+M$ |
| $A$ | $n\times n$ | 注意力权重 $\operatorname{softmax}(S')$；第 $i$ 行为 $a_i$ |
| $O$ | $n\times d_v$ | 单头注意力输出 $AV$；第 $i$ 行为 $o_i$ |
| $O_{\text{cat}}$ | $n\times Hd_v$ | 多头输出的拼接 |
| $Y$ | $n\times d$ | 模块最终输出（多头拼接并投影后） |

### 4.4 位置编码

| 符号 | 含义 |
| --- | --- |
| $t_i$ | 第 $i$ 个 token 的位置编号，$t_i=i-1$ |
| $P$ | 位置矩阵 $\in\mathbb{R}^{n_{\max}\times d}$，第 $i$ 行 $p_i$ 是位置编号 $t_i$ 的位置向量；$P_{1:n}$ 为前 $n$ 行 |
| $\operatorname{PE}(t)$ | 正余弦位置编码函数，$\mathbb{R}^{1\times d}$ 中的行向量 |
| $b$ | RoPE / 正余弦编码的底数（base），原始取值 $10000$ |
| $\omega_r$ | 第 $r$ 组的角频率 $b^{-2r/d_k}$（正余弦编码中把 $d_k$ 换成 $d$） |
| $\theta_{i,r}$ | 第 $i$ 个 token 在第 $r$ 组上的旋转角 $t_i\omega_r$ |
| $R_\omega(t)$ | 角频率 $\omega$、位置 $t$ 的 $2\times2$ 旋转矩阵（右乘） |
| $R(t)$ | 由各组 $R_{\omega_r}(t)$ 组成的 $d_k\times d_k$ 块对角旋转矩阵 |

### 4.5 长上下文扩展

| 符号 | 含义 |
| --- | --- |
| $s$ | 扩展倍数 $n_{\text{ext}}/n_{\text{train}}$ |
| $\lambda_r$ | 第 $r$ 组的波长 $2\pi/\omega_r$ |
| $\rho_r$ | 训练窗口内第 $r$ 组转过的圈数 $n_{\text{train}}/\lambda_r$ |
| $\rho_{\text{lo}},\rho_{\text{hi}}$ | 分频插值的圈数阈值 |
| $\xi_r$ | 第 $r$ 组保留原频率的比例（0 = 完全插值，1 = 不插值） |
| $\omega'_r$ | 插值后的角频率 |
| $\tau$ | softmax 温度 |
| $\alpha$ | YaRN 对 Q、K 的幅度倍率，$\tau=1/\alpha^2$ |

### 4.6 与论文 / 框架写法的对照

读原论文时符号常常和本库不同，对照如下：

| 来源 | 原写法 | 本库写法 | 改动原因 |
| --- | --- | --- | --- |
| Transformer 原论文 | $PE(pos,2i)$ | $\operatorname{PE}(t)_{2r+1}$ | $i$ 已用于 token 下标 |
| Transformer 原论文 | $d_{\text{model}}$ | $d$ | 简洁 |
| 不少代码 | `T`、`L`、`seq_len` | $n$ | 统一序列长度 |
| PyTorch BatchNorm2d | `(N, C, H, W)` | $(B,C,H_{\text{img}},W_{\text{img}})$ | $N$、$H$、$W$ 已被占用 |
| PyTorch | `momentum` | $\kappa$ | $m$ 已用于集合大小 |
| YaRN 论文 | $L$、$L'$ | $n_{\text{train}}$、$n_{\text{ext}}$ | 统一长度用 $n$ |
| YaRN 论文 | $\gamma(r)$、$\alpha$、$\beta$ | $\xi_r$、$\rho_{\text{lo}}$、$\rho_{\text{hi}}$ | $\gamma,\beta$ 保留给归一化 |
| YaRN 论文 | 温度 $t$ | $\tau$ | $t$ 保留给位置编号 |

## 5. 常用运算的定义

**行 softmax**：对矩阵 $Z\in\mathbb{R}^{n\times n}$ 的每一行独立归一化：

$$
\operatorname{softmax}(Z)_{ij}=\frac{\exp(Z_{ij})}{\sum_{j'=1}^{n}\exp(Z_{ij'})}.
$$

全库的 $\operatorname{softmax}$ 都指按行（沿 key 方向，代码中 `dim=-1`）。

**加性 mask**：$M_{ij}=0$ 表示第 $i$ 个 query 可以看第 $j$ 个 key，$M_{ij}=-\infty$ 表示屏蔽。因果 mask：

$$
M_{ij}=
\begin{cases}
0, & j\le i,\\
-\infty, & j>i.
\end{cases}
$$

**拼接**：$O_{\text{cat}}=\operatorname{Concat}(O^{(1)},\dots,O^{(H)})$ 沿列方向（特征维）拼接，$n\times d_v$ 的 $H$ 块拼成 $n\times Hd_v$。

**块对角**：$\operatorname{diag}(R_1,\dots,R_k)$ 表示把方块矩阵沿对角线排列，其余位置为 $0$。

## 6. 数学 ↔ 代码对照

| 数学 | 代码 | 代码形状 |
| --- | --- | --- |
| $X$ | `x` | `[B, n, d_model]` |
| $W_Q$ | `W_q`（显式矩阵）或 `q_proj.weight.T`（`nn.Linear`） | `[d_model, d_k]` |
| $Q,K,V$ | `q, k, v` | `[B, n, d_k]`；多头为 `[B, H, n, d_k]` |
| $S$ | `scores` | `[B, n, n]`；多头为 `[B, H, n, n]` |
| $M$ | `mask`（bool，`True` 表示屏蔽） | `[n, n]` |
| $A$ | `attn` | 同 $S$ |
| $O$ | `out` | `[B, n, d_v]` |
| $t_i$ | `t = torch.arange(n)` | `[n]` |
| $\omega_r$、$\omega'_r$ | `omega`、`omega_prime` | `[d_k // 2]` |
| $\gamma,\beta$ | `gamma, beta` | `[d]` |
| $\epsilon$ | `eps` | 标量 |

> [!warning] 两个容易踩的坑
> 1. `nn.Linear(d_in, d_out)` 内部存的 `weight` 形状是 `[d_out, d_in]`，计算的是 `x @ weight.T + bias`。所以数学上的 $W\in\mathbb{R}^{d_{\text{in}}\times d_{\text{out}}}$ 对应 `weight.T`。
> 2. 本库代码中 bool `mask` 的 `True` 表示**屏蔽**（配合 `masked_fill(mask, -inf)`）；而 `F.scaled_dot_product_attention` 的 bool `attn_mask` 中 `True` 表示**允许**，两者正好相反。

## 7. LaTeX 书写规范

- 转置写 `^\top`；多字母函数写 `\operatorname{...}`；实数集写 `\mathbb{R}`；文字下标写 `\text{...}`。
- 多行公式用 `$$ \begin{aligned} ... \end{aligned} $$`，**公式块内不留空行**（空行会让 Obsidian 渲染出错）。
- 单个字母的修饰用 `\tilde`、`\hat`，不用 `\widetilde`、`\widehat`。
- 行内公式两侧不加多余的 `{}`，例如写 `$h$`，不写 `${}h{}$`。
- 公式末尾的标点（逗号、句号）写在公式块里面，跟在公式之后。
